Claude Codeは**Claude Consoleアカウントでログインすれば、APIキーなしで**そのまま使えます。このページは、APIキーを使いたい場合の補足です。

## APIキーが必要になるケース

- 普段はPro/Maxプランでログインしていて、**このセッションだけAPIクレジットを使いたい**
- ブラウザでのログイン操作ができない環境（サーバー、CI など）で動かす
- Claude Code以外に、自分で書いたスクリプトやSDKからAPIを呼びたい

## APIキーを発行する

<Steps>

1. コンソールの「APIキー」メニューを選択し、「キーを作成」をクリックします。

    ![](../images/2026-07-04-23-33-46.png)

1. 名前を入力し、「追加」をクリックします。表示されたAPIキー（`sk-ant-`で始まる文字列）を控えます。**作成時にしか表示されません。**

    ![](../images/2026-07-04-23-36-09.png)

</Steps>

<Aside type="caution" title="「Claude Code」ワークスペースではAPIキーを作れません">
	Claude ConsoleアカウントでClaude Codeにログインすると自動作成される「Claude Code」ワークスペースは、Claude Codeの認証と使用量の集計専用です。APIキーは`Default`など別のワークスペースで作成してください。APIキーはワークスペース単位で発行され、そのワークスペースの残高・上限が適用されます。
</Aside>

## APIキーを設定する

環境変数 `ANTHROPIC_API_KEY` に設定してからClaude Codeを起動します。

<Tabs syncKey="os">

<TabItem label="macOS">

```sh
export ANTHROPIC_API_KEY="ここにAPIキー"
claude
```

</TabItem>

<TabItem label="Windows">

```powershell
$env:ANTHROPIC_API_KEY = "ここにAPIキー"
claude
```

</TabItem>

</Tabs>

<Aside type="caution" title="ウィンドウを閉じると消えます">
	この設定はそのターミナルの中だけで有効です。永続化したい場合は、macOSは`~/.zshrc`への追記、Windowsは「環境変数の編集」から設定してください。APIキーをスクリプトのコードに直接書いたり、GitHubにコミットしたりしないよう注意してください。
</Aside>

## どの認証で動いているか確認する

環境変数はログイン情報より**優先**されます。古い`ANTHROPIC_API_KEY`が残っていると（空文字でも）そちらが使われるので、ログイン情報で認証したい場合は環境変数を削除してください。

Claude Codeの起動中に `/usage` や `/login` を開くと、いまどのアカウント・どの認証で動いているかを確認できます。
