<Aside type="note" title="Claude Codeの利用も同じ「API利用」です">
	Claude ConsoleアカウントやAPIキーでClaude Codeを使うと、通常のAPI利用と同じようにトークン単位で課金され、クレジットから引かれます。したがって、**コンソールで設定した支出上限はClaude Codeの利用にもそのまま効きます**。
</Aside>

## 組織全体の月額支出上限を設定する

予期せぬ課金を防ぐため、上限を設定しておくことをおすすめします。

<Steps>

1. 「組織の設定」の中にある「請求」メニューをクリックします。

1. 「月額支出上限」の「制限を調整」をクリックし、制限をセットします。

    ![](../images/2026-08-10-03-37-26.png)

</Steps>

## ワークスペース単位で上限を設定する

Claude ConsoleアカウントでClaude Codeにログインすると、「**Claude Code**」という名前のワークスペースが自動で作られ、Claude Codeの利用はすべてここに集計されます。

このワークスペースに支出上限を設定すると、**Claude Codeの利用だけを上限つきにできます**。他のAPI利用（自分で書いたスクリプトなど）と分けて管理したい場合に便利です。設定はコンソールのワークスペース設定から行います。

## 使った金額を確認する

| 確認する場所 | 分かること |
| :--- | :--- |
| Claude Code内で `/usage` | いまのセッションで使ったトークン量・金額の目安 |
| [コンソールの使用状況ページ](https://platform.claude.com/usage) | 正式な利用実績・残高 |
| [Claude Codeダッシュボード](https://platform.claude.com/claude-code) | メンバーごとのClaude Code利用状況 |

`/usage` の金額はローカルで計算した**目安**です。正確な請求はコンソール側を確認してください。

## コストを抑えるコツ

Build Dayの数時間で使う分にはそれほど気にする必要はありませんが、覚えておくと日常でも役立ちます。

- **別の作業に移るときは `/clear`**：会話が長いほど、毎回のやりとりで消費するトークンが増えます。関係ない作業に移るときはリセットするのが一番効きます。
- **モデルを使い分ける**：`/model` で切り替えられます。込み入った設計判断以外は軽いモデルでも十分こなせます。
- **お願いを具体的にする**：「このコードをよくして」より「`index.html`のフォーム送信時に入力チェックを追加して」の方が、余計なファイル読み込みが減って速く安く済みます。
- **違う方向に進んだら `Escape`**：早めに止めて指示し直す方が、そのまま進ませて作り直すより安上がりです。
