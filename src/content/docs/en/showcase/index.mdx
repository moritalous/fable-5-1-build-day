**These are the prompts we actually gave Fable 5.1, along with exactly what came out of them.** All six were produced from a single prompt, with no follow-up instructions at all. You can run the generated HTML for yourself in a new tab.

<Aside type="tip" title="The prompts are yours to copy">
	You can copy the prompt on each page exactly as it is. Sending it as-is and then steering the result in your own direction is the quickest way to get started on the day.
</Aside>

All six are **a single HTML file with no external libraries, images or network calls**. Download one and it still runs offline. Even the examples that use a camera or microphone (2 and 6) process the video and audio entirely inside the browser; nothing is sent anywhere.
