## What is a Build Day?

A Build Day is **a session for experiencing a new model by actually building with it**. While people around the world are trying out Fable 5.1, let's get together, build, and show each other what we made.

Build whatever you want. Something you couldn't build before, something that solves a daily annoyance, something surprising — any direction is welcome. Engineers and developers are of course welcome, and so is anyone interested in building with Claude, regardless of experience. **It's fine if you've never used Claude Code.** The [Setup](/en/preparation/account/) pages walk you through everything from creating an account to running Claude Code.
