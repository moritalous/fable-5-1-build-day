作業用のフォルダを作り、APIキーを設定して、実際に起動するところまで進めます。ここまでできていれば当日は作るだけです。

## 作業用のフォルダを作る

Claude Codeは「いま開いているフォルダ」を作業場所にします。散らからないよう、専用のフォルダを作っておきましょう。

<Tabs syncKey="os">

<TabItem label="macOS">

```sh
mkdir -p ~/build-day
cd ~/build-day
```

</TabItem>

<TabItem label="Windows">

```powershell
mkdir $HOME\build-day
cd $HOME\build-day
```

</TabItem>

</Tabs>

## APIキーを設定する

作業フォルダの中に設定ファイルを置くと、**ターミナルを開き直してもキーが残ります**。毎回入力する必要はありません。

<Steps>

1. 設定ファイルを作って開きます。作業フォルダ（`build-day`）にいる状態で実行してください。

    <Tabs syncKey="os">

    <TabItem label="macOS">

    ```sh
    mkdir -p .claude
    touch .claude/settings.json
    open -e .claude/settings.json
    ```

    テキストエディットで空のファイルが開きます。

    </TabItem>

    <TabItem label="Windows">

    ```powershell
    New-Item -ItemType Directory -Force .claude | Out-Null
    if (!(Test-Path .claude\settings.json)) { "" | Set-Content .claude\settings.json }
    notepad .claude\settings.json
    ```

    メモ帳で空のファイルが開きます。

    </TabItem>

    </Tabs>

1. 次の内容を貼り付け、`ここにAPIキー` を[発行したキー](../apikey/)（`sk-ant-`で始まる文字列）に置き換えて保存します。

    ```json
    {
      "env": {
        "ANTHROPIC_API_KEY": "ここにAPIキー"
      }
    }
    ```

</Steps>

<Aside type="caution" title="このファイルは人に渡さないでください">
	`settings.json`にはAPIキーがそのまま書かれています。**作業フォルダをGitHubなどに公開すると、キーごと公開されます。** 作ったものを共有するときは、HTMLファイルだけを渡してください。
</Aside>

## 起動する

<Steps>

1. `claude` と入力してEnterを押します。

    ```sh
    claude
    ```

1. Claude Codeのプロンプトが表示されれば準備完了です。バージョン・使用中のモデル・作業ディレクトリが上部に出ています。**APIキーが設定されていればログインは求められません。**

</Steps>

## どの認証で動いているか確認する

APIキーはログイン情報より**優先**されます。起動中に `/usage` や `/login` を開くと、いまどのアカウント・どの認証で動いているかを確認できます。

<Aside type="caution" title="Pro/Maxプランを契約している方はご注意ください">
	すでにPro/Maxプランでログインした状態のPCでAPIキーを設定すると、**キーのほうが優先されてAPIクレジットが消費されます**。逆に、APIクレジットを使いたいのにキーを設定し忘れると、サブスクリプションの枠で動いてしまいます。どちらで動かすか決めてから起動してください。

	サブスクリプションの枠で動かしたい場合は、`.claude/settings.json`を作らずに `claude` を起動してログインしてください。すでに作ってしまった場合は、そのファイルを削除すればログイン側に戻ります。
</Aside>

## 最初の1つを作ってみる

プロンプトに日本語でそのまま書いて、Enterを押します。

```text
このフォルダに、今日の日付を表示するだけのHTMLファイルを作って
```

Claudeがファイルを作り、変更内容を見せて、実行の許可を求めてきます。承認すると作業が進みます。**ファイルを変更する前には必ず許可を求める**ので、勝手に壊されることはありません。

慣れてきたら、こんな頼み方も試してみてください。

```text
作ったHTMLをブラウザで開いて見せて
```

```text
背景をグラデーションにして、時計も表示するようにして
```

## 覚えておくコマンド

Claude Codeを起動したあと、`/` から始まるコマンドが使えます。全部覚える必要はありません。

| コマンド | 何をするか |
| :--- | :--- |
| `/help` | 使えるコマンドの一覧 |
| `/login` | ログインし直す・アカウントを切り替える |
| `/usage` | いまのセッションで使った量・金額の目安 |
| `/clear` | 会話をリセットする（別の作業に移るとき） |
| `/model` | 使うモデルを切り替える |
| `/exit` | 終了する（`Ctrl+D`でも可） |

キー操作では、`Shift+Tab`で許可モードの切り替え、`Escape`で実行中の中断ができます。「違う方向に進みだしたな」と思ったら遠慮なく`Escape`を押してください。

<Aside type="tip" title="困ったらClaude自身に聞く">
	Claude Codeの使い方は、Claude Codeに聞くのが一番早いです。`できることを教えて` `さっきのエラーはどういう意味？` のように、そのまま日本語で聞いてください。
</Aside>
