ここまでの6作品はすべて単一のHTMLファイルですが、Fable 5.1が作れるものはそれだけではありません。主催者（[moritalous](https://github.com/moritalous)）が実際に作らせたmacOSアプリを2つ紹介します。どちらもSwiftで書かれたネイティブアプリです。

## AltTabの再現（WindowsのAlt+TabをmacOSで）

<p class="badges"><Badge text="オリジナル" variant="tip" /><Badge text="$27.61" variant="success" /></p>

Windowsの`Alt+Tab`によるウィンドウ切り替えをmacOSで再現するアプリを作らせたときの投稿です。

<XPost url="https://x.com/moritalous/status/2097302855422234705" />

ソースコードは[moritalous/alt-tab-mac](https://github.com/moritalous/alt-tab-mac)にあります。このときのプロンプトは残っていません。

### 実測値（トークン使用量）

所要時間は記録が残っておらず不明です。モデルは`claude-fable-5-1`です。

| 項目 | トークン数 | 単価 | 金額 |
| :--- | ---: | ---: | ---: |
| Base input | 2,876 | $10/MTok | $0.03 |
| 1h cache write | 771,636 | $20/MTok | $15.43 |
| Cache read | 13,114,988 | $0.25/MTok | $3.28 |
| Output | 177,441 | $50/MTok | $8.87 |
| **小計** | **14,066,941** | — | **$27.61** |

<Aside type="note">
	各項目の料金は四捨五入しているため、小計と一致しない場合があります。料金はセッションログから算出した目安です。
</Aside>

## Windowsスタイルのファイルエクスプローラー

<p class="badges"><Badge text="オリジナル" variant="tip" /><Badge text="$54.02" variant="success" /><Badge text="52分" variant="tip" /></p>

macOSにWindowsスタイルのファイルエクスプローラーを作らせたときの投稿です。

<XPost url="https://x.com/moritalous/status/2098930080680739180?s=20" />

## 使ったプロンプト

```text wrap
最近macを使い始めました。それまではWindowsでした。　FinderよりWindowsのエクスプローラーのほうが圧倒的に使いやすいです。なので、macで動くエクスプローラーのようなアプリを作ってください。見た目、機能など、あなたの実力を最大限発揮して、可能な限りWindowsのものに寄せてください。細かなことはわからないので、あなたの考える最高のエクスプローラーを作って。

これから寝るので、朝起きたら出来上がってるのが理想。途中で質問されても答えられないので、自分で考えて進めてください。
```
