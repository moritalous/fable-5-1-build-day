架空の星系を真上から見たシミュレーターです。惑星は本物のニュートン重力で動き、シミュレーション自身が測った公転周期を、ケプラーの第三法則が予測する値と突き合わせて、1%以内で一致したら行が緑になります。

<DemoLink file="star-system.html" />

## 何ができるか

- 恒星1つと惑星6つ。名前・色・軌道の大きさはモデルが考えたもので、1つははっきりした楕円軌道
- 惑星ごとに「軌道長半径 / 実測した公転周期 / ケプラーの第三法則による予測値 / 誤差%」を表示。1%以内なら緑
- 系全体のエネルギーと、開始時からのドリフト（ずれ）を表示
- 惑星をクリックで追尾、スクロールでズーム、スライダーで時間の速さを変更
- ボタンでランダムな惑星を追加。追加した惑星もその場から計測対象になる
