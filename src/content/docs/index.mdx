## Build Dayとは

Build Dayは、**新しいモデルを実際に手を動かして体験する回**です。世界中の人がFable 5.1を試しているこのタイミングで、集まって、作って、見せ合いましょう。

作るものは自由です。「これまで作れなかったもの」「日々の困りごとを解決するもの」「びっくりするもの」など、どんな方向でも歓迎です。エンジニア・開発者の方はもちろん、Claudeでのものづくりに関心がある方であれば経験は問いません。**Claude Codeを使ったことがない方でも大丈夫です。**[セットアップ](/preparation/account/)のページに、アカウント作成からClaude Codeを動かすところまでの手順を用意しました。

## 何を作るか迷ったら

**Fable 5.1に実際に投げたプロンプトと、そこから出てきたHTMLを6作品ぶん公開しています。** すべて追加指示なしの一発生成で、生成物は別タブで実際に動かせます。かかった時間と料金（1本あたり$9〜$24）も載せているので、当日の見通しを立てる材料にしてください。

プロンプトはコピーしてそのまま使えます。まず投げてみて、出てきたものを自分の好きな方向に変えていくのが、いちばん手早いスタートです。
