## Build Dayとは

Build Dayは、**新しいモデルを実際に手を動かして体験する回**です。世界中の人がFable 5.1を試しているこのタイミングで、集まって、作って、見せ合いましょう。

作るものは自由です。「これまで作れなかったもの」「日々の困りごとを解決するもの」「びっくりするもの」など、どんな方向でも歓迎です。エンジニア・開発者の方はもちろん、Claudeでのものづくりに関心がある方であれば経験は問いません。**Claude Codeを使ったことがない方でも大丈夫です。**[事前準備](/preparation/account/)のページに、インストールからログインまで手順を用意しました。
